Пищевая ценность на 100 г

Порция: 300 г · 450 ккал
Как это работает

Фото уменьшается и отправляется в Google Gemini только когда ты нажимаешь «Распознать». ИИ оценивает состав и порции приблизительно — проверь результат перед сохранением.

Подключение ИИ

Нужен бесплатный ключ Gemini: открой aistudio.google.com/apikey, войди в Google-аккаунт, нажми «Create API key» и вставь ключ сюда. Ключ хранится только в этом браузере.

Расширенно: свой сервер на Supabase (необязательно)

Если ключ Gemini заполнен выше, используется он. Сервер нужен только если не хочешь хранить ключ в браузере.
