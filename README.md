# NutriTrack AI v5 — личный дневник питания

Мобильный сайт для личного использования: дневник калорий и КБЖУ, профиль с расчётом нормы, фото еды с ИИ-распознаванием, недельный отчёт.

## Что изменилось в v5
- **ИИ снова работает.** Раньше сайт обращался к модели `gemini-2.5-flash-lite`, которую Google отключает (16 октября 2026), и требовал отдельно развернуть сервер на Supabase. Теперь достаточно вставить бесплатный ключ Gemini прямо в приложении. Модель выбирается автоматически из доступных ключу, с запасными вариантами.
- Исправлена ошибка, из-за которой нельзя было сохранить блюдо с дробным КБЖУ после распознавания.
- Добавлены отдельные кнопки «Сделать фото» и «Выбрать из галереи» (раньше на телефоне открывалась только камера).
- Фото из дневника открывается внутри приложения (раньше его блокировал браузер).
- Работает импорт из резервной копии JSON.
- Исправлено дублирование фото в недельной галерее.
- Понятные сообщения об ошибках (неверный ключ, лимит запросов, регион, нет интернета).
- Добавлены иконки, приложение можно установить на главный экран.

## Как включить ИИ (1 минута)
1. Открой https://aistudio.google.com/apikey, войди в Google-аккаунт, нажми **Create API key**, скопируй ключ.
2. На сайте: **Фото еды → Подключение ИИ** → вставь ключ → **Сохранить** → **Проверить ключ**.
3. Выбери фото → **Распознать еду на фото** → проверь результат → **Сохранить**.

Ключ хранится только в localStorage твоего браузера и отправляется только в Google. Не публикуй сайт с ключом внутри кода и не делись своим ключом. Если Gemini недоступен в твоём регионе, понадобится VPN. Условия и лимиты бесплатного тарифа: https://ai.google.dev/gemini-api/docs/pricing

## Размещение
Залей содержимое папки на GitHub Pages (Settings → Pages → Deploy from a branch → `main` → `/ (root)`) или любой HTTPS-хостинг. Для камеры и установки на экран нужен HTTPS. Локально: `python3 -m http.server`, затем http://localhost:8000.

## Приватность
- Профиль и записи: `localStorage`; фото: `IndexedDB` браузера. Ничего не синхронизируется между устройствами.
- Фото уходит в Google Gemini только когда ты нажимаешь «Распознать».
- ИИ может ошибаться в ингредиентах, весе, масле и соусах — это оценка, а не лабораторный расчёт. Всегда проверяй результат.
- При очистке данных браузера записи и фото исчезнут. Делай экспорт JSON в разделе «Профиль».

## Необязательно: свой сервер (Supabase)
Если не хочешь хранить ключ в браузере, можно развернуть `supabase/functions/analyze-food`:

```bash
supabase login
supabase link --project-ref YOUR_PROJECT_REF
supabase secrets set GEMINI_API_KEY=... APP_ACCESS_CODE=длинный-случайный-код
supabase functions deploy analyze-food --no-verify-jwt
```
Затем в приложении открой «Расширенно: свой сервер», вставь URL `https://YOUR_PROJECT_REF.supabase.co/functions/v1/analyze-food` и код доступа (поле с ключом Gemini оставь пустым).
